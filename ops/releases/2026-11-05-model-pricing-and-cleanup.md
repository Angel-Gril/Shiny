## 分组/渠道价格边界

New API 当前模型定价按“请求模型名”全局解析，不能让同一个公开模型名在不同渠道或分组中自动使用两套表达式。分组倍率只会对同一模型的结果做乘法，也不能把 Token 计费变成固定的每张图片价格。

当前采用模型别名实现分流：

- CPA 普通图片模型继续使用 Token/图片输入表达式；
- 低价图片渠道使用 gpt-image-2-cdn 等别名，表达式为 tier("image", fixed(0.02)) * image_count；
- 渠道模型列表只暴露各自需要的别名。

如果以后必须让用户提交同一个模型名、但由不同分组选择不同基础表达式，需要修改 New API 的计费上下文，把渠道/分组带入定价键；这属于代码级计费改造，当前没有实施。现在的低价图片渠道用 -cdn 别名，CPA 按 Token 计费的渠道继续使用普通图片模型名。
