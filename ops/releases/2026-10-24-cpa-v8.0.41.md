# CPA v8.0.41

2026-10-24（Asia/Shanghai）生产 CPA 从 v8.0.40 升级至官方稳定版 v8.0.41。只切换 CPA 程序；New API、CPAMP、门户和 Nginx 未重启。

## 官方变更

- 新增 Home 集群延迟遥测和探测。
- 修复 Claude commentary 阶段映射为 thinking block。
- 修复 Claude 空对象 schema 的工具参数保留。
- 修复 Gemini 首个函数调用签名、模型 token 限制、Vertex finish reason 和 `$ref` 兄弟约束。
- 增加 RESP 协议边界校验与连接 panic 恢复。
- 修复 Interactions 流 usage token 语义合并。

本版本没有列出插件 ABI、Key Router、账号并发或 Management API 的破坏性变更。官方源码 tag commit 为 `8289ec4c71ad914d0612c2776352b76ba3d355a0`。
