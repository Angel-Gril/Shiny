# CPA Manager Plus Full v1.14.10

2026-10-29（Asia/Shanghai）生产 CPAMP 从官方 v1.14.9 更新到 v1.14.10。使用官方 Full 二进制及其内嵌前端，不修改 CPA 内核或本站 New API 源码。

## 升级收益与兼容性

- 历史价格查询优先使用完整的原始用量事件，避免价格投影缺失导致统计查询失败，不补造已丢失事件。
- 模型排除规则按实际 CPA 版本展示，匹配 v8.0.33+ 的凭证级覆盖规则。
- 插件设置显示声明的默认值，保留管理员显式保存的 false、0、空值。
- 修复同页筛选、搜索和 URL 状态同步；新增仅保存在当前浏览器的凭证置顶。
- 新增管理员限定的 CPA v8 API Key 分组只读代理。

官方比较范围没有修改数据库 schema、迁移、配置格式、采集器和 Go 依赖。固定源码为 `a67ed8834a914ab24c36d2490fa6bb6d4166724c`，最低 CPA 基线仍为 v7.3.4。
