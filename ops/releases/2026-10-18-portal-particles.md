## 用户可见行为

- 暖灰/深色粒子首屏，31 个分组造型，默认 Shiny；支持自动轮播、暂停、选择和局部粒子笔刷。
- 标题和简介继续使用已发布内容；API 示例紧邻首屏下方。首页文字、导航和复制不等待粒子引擎，不加载文档或上传模块。
- 窄屏及低性能设备默认静态，允许手动播放；减少动态/省流模式保持静态。后台、离屏、路由离开暂停绘制或释放资源；画布失败显示静态图。
- 桌面 30000 点、移动播放 10000 点，DPR 上限 1.25，目标 30fps，生成模型缓存最多 4 个。场景模块按组加载，无外部 CDN。
- 保留上游 AGPL/NOTICE、轮廓 MIT、字体 OFL 及修改说明；页脚提供可见致谢、许可和对应提交的源码入口。没有迁入交接包里的提示词、演示 HTML/导航、截图、启动或抓取脚本。

## 验证

31 场景、不可变采样、缓存、主题、DPR 和销毁回归，13 项真实浏览器粒子检查及 9 项原有文档/搜索/多文件/R2 上传回归通过。源码密钥扫描和 PR 的门户/New API CI 均通过。响应式覆盖 320/390/768/1440/2048、双主题及 200% 布局模拟。

候选及公网验证实际内容、导航、下载、MIME、来源入口和旧版资源，无脚本异常或新资源 404；窄屏默认不下载引擎。公网同一 1440×900 浏览器的 4 秒播放产生 121 帧、主线程任务约 730ms；暂停 2 秒 0 帧/3ms，离屏 2 秒 0 帧/17ms。该结果是本机浏览器测量，不能代表手机真机或所有设备的持续性能。

公网连续轮播 110 秒，已实际显示全部 10 个精选造型，无脚本异常或资源错误。减少动态在运行中开启后切为静态，关闭后保留原先的用户暂停状态；触屏模拟通过画布原生滑动，页面滚动 145px。实际回退探针没有命中浏览器 BFCache，因此其暂停原因覆盖仍以合成 PageTransitionEvent 测试为依据，不宣称实测命中缓存恢复。

## 公网加载测量

同一客户端分别使用五个无缓存浏览器上下文，再在各自上下文中刷新。文字指标为主要内容写入 DOM，动画指标为首帧完成标记；两者均不等同于 LCP。参考前一版 v15 的同日测量，不将网络波动归因为动画优化。

| 指标 | v15 | v17 |
|---|---|---|
| 冷缓存文字五次 | 3293 / 1594 / 2322 / 2029 / 2225 ms | 1778 / 2115 / 2308 / 2003 / 1624 ms |
| 冷缓存文字中位数 | 2225 ms | 2003 ms |
| 冷缓存动画首帧 | 无粒子 | 3160 / 3511 / 4060 / 2997 / 2572 ms，中位 3160 ms |
| 热缓存文字中位数 | 558 ms | 569 ms |
| 热缓存动画首帧中位数 | 无粒子 | 621 ms |

v17 内容显示前资源传输约 177KB，动画首帧前约 257KB（不含导航 HTML）。字体和引擎在内容显示后加载。首次访问仍观测到 88–94ms 的单次长任务，后续如需继续优化可针对首次几何生成做分段或 Worker；本次不增加这类架构。热缓存五轮未观测到长任务。
