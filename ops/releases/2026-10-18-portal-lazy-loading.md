代码来自 [PR #5](https://github.com/Angel-Gril/Shiny/pull/5)，源码提交 `e4d4d8f6d829a6a63406b60cda39caa4643f3475`，合并提交 `208426206b1e6f745d5a35459e1217fcaf303db5`。

前端已发布 `portal-20261018-v15`。18 个前端文件的包 SHA-256 为 `412a8e198dd35ba628316c9c6805ddbb8a0c3bb3698a7823c00cb9f7d45cc1b6`。内容服务的 `current` 链接和 `production_release` 仍是 `portal-20261017-v14`，没有更新或重启后台服务；前端版本在组件清单单独记录。

## 首屏行为

- HTML modulepreload 提前取应用，轻量 `boot.js` 并行请求公开内容。
- 首页、下载和公告不下载 Markdown、净化库、上传队列或 R2 分片模块；文档/搜索及认证后的管理功能按需加载。
- 继续使用原清理、链接映射、正文搜索和上传引擎；异步路由/搜索结果不会覆盖后续操作。失败时保留导航并提供重载入口。
- 样式与 0.55 秒入场动画保持原样。没有在本次修改 HTTP 版本、压缩配置、内容数据或缓存策略。

## 公网测速

同一客户端分别使用三个无缓存浏览器上下文首访，再在各自上下文中刷新。指标为首页主要内容写入 DOM 的时间，包含网络与脚本加载；不等同于完整页面加载或 LCP。不同用户网络下会变化。

| 指标 | 修改前 | 发布后 |
|---|---|---|
| 无缓存首屏三次 | 4638 / 3802 / 4886 ms | 2725 / 2409 / 2871 ms |
| 无缓存首屏中位数 | 4638 ms | 2725 ms（约减少 41%） |
| 首屏资源传输量 | 400922 bytes | 164239 bytes（约减少 59%） |
| 缓存后刷新三次 | 690 / 694 / 1019 ms | 735 / 378 / 383 ms |

本次优化主要消除了可选依赖与串行等待。缓存后数据同时受网络波动影响，不将其全部归因于代码变化。候选地址的耗时不用于和公网直接比较。

## 验收和发布

9 项浏览器回归、30 项 Python 测试及 PR CI 通过。候选与公网验证首页、下载、文档、搜索、手机布局和旧版本资源，均无脚本异常或新资源 404；测试包含真实本地文件上传和模拟 R2 签名 PUT，没有向生产桶上传测试文件。

仅将主站的独立门户 include 切到新前端，保留 v14 及更旧的不可变资源路径。Nginx 重载是异步交接，发布检查等待新版本连续响应两次；第一次即时检查读到旧 worker 后已自动回退，再核实交接时序并完成切换，服务没有重启。内容服务、New API、CPA、CPAMP 的 PID 和 R2 设置摘要保持不变。临时候选监听及上传包已清理。

回滚仅需将门户 include 恢复为 `/opt/shiny-portal/releases/portal-20261017-v14/portal-locations.conf`，执行 `nginx -t` 后平滑重载，并确认新连接实际读到旧版本；不还原数据库，不切内容服务 current，不重启模型服务。新旧资源目录暂时均保留以兼容打开中的标签页。
