- 首页、教程列表/阅读、下载和公告统一暖纸色、暖黑主题、细线、轻圆角和排版层级。增加本地 `paper.css`，没有新增字体、图片、脚本依赖或纹理动画。
- 当前中文标题使用已发布内容的换行，通过文字列宽和流式字号保持两行；任意自定义长文案允许自然换行，不硬编码或删减内容。导航、首屏和首页下方共享容器边界，宽屏内容上限 1520px。
- 代码示例取消倾斜、冷白外框和阴影；首页下方栏目、教程和公告采用相同字重与间距。
- 下载简介与大小/架构分开布局，取消每条元数据 40px 的段落最小高度。2048px 实际内容下 CC Switch 卡片从约410px降至317px，模板卡片约288px，保留全部资源/教程 URL 和 SHA-256。
- 宽屏阅读正文列上限800px，中等屏幕改用两列及文章内目录；目录行样式和切换断点同步到1200px。管理页保留工作台样式，公开与管理页互跳验证视觉类正确切换。

## 验证证据

15 项真实构建页面/粒子浏览器检查、9 项既有文档/搜索/多文件/R2直传回归、密钥扫描和 PR 的门户/New API CI 均通过。新增覆盖默认中文标题两行及对齐、长资源名称/架构、系统/分类/文本筛选、下载地址、校验值、多标题目录和管理页样式隔离。

候选和公网分别验证 320/390/768/1024/1440/2048 下四类公开页面、双主题，共48种组合，无横向溢出或脚本错误；另截图检查实际教程阅读页，并以1150px多标题夹具验证目录条目独占一行。响应式和触屏仍为浏览器模拟。

公网播放4秒120帧，主线程任务约707ms；暂停2秒0帧/1ms，离屏2秒0帧/20ms。v17、v15、v14资源继续200可用；手机默认静态且不下载引擎，来源/许可入口固定到此次源码提交。

## 部署、观察与回滚

只将独立门户 Nginx include 从v17切到v18，语法校验后平滑重载，等新版本连续响应两次。内容服务 `current` 和 `production_release` 仍为 `portal-20261017-v14`。内容服务、New API、CPA、CPAMP PID 和 R2 设置摘要不变；没有后台、账单、数据库或存储配置变更。

候选监听、上传包和隧道在验收后清理。保留所有正式不可变资源，防止旧标签页失效。私有部署回执、配置恢复记录、5分钟健康观察和浏览器证据在 `/root/shiny-maintenance/portal-paper-20261018/` 及本机忽略的维护目录，不纳入 Git。

如出现白屏、新资源错误、下载或目录操作异常，将主站门户 include 恢复为 `/opt/shiny-portal/releases/portal-20261018-v17/portal-locations.conf`，执行 `nginx -t` 和平滑重载，等旧版本连续响应两次。不切后端 current、不恢复数据库、不删除用户文件。
