# 门户启动兼容修复

Edge 92 不支持 `structuredClone`，门户成功取得公开 JSON 后，在复制发布内容时抛出异常，统一错误页把它显示为网络失败。已在公网旧发布页中禁用该能力复现同样提示；同时段访问记录中脚本、样式与内容请求均成功。另一张登录页无样式的截图属于 New API 控制台使用现代 CSS 的兼容边界，建议更新浏览器。

门户只复制 JSON 数据，现增加 JSON 序列化回退，保留支持该能力的浏览器原有行为。内容请求、模块加载和初始化失败分别提示，控制台记录原始异常，不把异常文本插入页面。

验证：新增浏览器回归先在旧实现上失败，修复后按需加载 12 项和控制台入口 10 项通过；公告与粒子回归结果见 PR。缺失能力测试在现代 Chromium 中模拟，不代表所有旧浏览器功能均已兼容。

发布使用独立的不可变门户静态 release，只切换 Nginx 门户 include。保留全部旧资源；内容数据库、R2 配置、New API 和其他服务保持原有生命周期。候选与公网需验证禁用 `structuredClone` 后的首页、教程、下载、控制台原生入口以及手机布局。失败时恢复上一个 include 并检查 `nginx -t` 后 reload。
