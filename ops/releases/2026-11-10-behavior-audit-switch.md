# 独立行为审计开关

配置键：`BehaviorAuditEnabled`。升级时未设置该键默认启用，保留原有行为；管理员可以在 **系统设置 → 请求策略 → 请求检查 → 行为审计** 修改并保存，运行进程即时读取。

关闭后，停止新建多令牌、多网络出口、模型切换、重试、连续失败、上游错误、长请求与频繁令牌操作等行为信号，并停止其 Redis 计数与冷却标记。已有计数保留至原有 TTL 到期，历史审计和复核记录保留。开启后重新记录；该开关不改变内容审核、关键词规则、管理员操作日志、请求限流、路由或计费。

实现复用请求策略的校验、事务保存和原子快照，不引入数据库表、字段或依赖；前端复用 SettingsSection、SettingsForm、SettingsSwitchItem 和 useSavePolicy，单独保存此项。

验证：

- 新增回归先验证旧实现失败，再验证关闭、即时重开、请求结果不变、无新增 Redis 状态、内容审核/操作日志独立记录。
- 中间件完整测试通过；前端请求策略与审计相关 143 个测试通过。
- SQLite 3.50.4、MySQL 8.0.46、PostgreSQL 16.15 的真实配置保存、重复加载、旧接口更新和非法值拒绝均通过。
- 前端类型、相关 lint、格式及生产构建检查通过。

部署版本、候选和生产验收信息随发布补充；不在 Git 保存凭据、运行数据或原始用户日志。
