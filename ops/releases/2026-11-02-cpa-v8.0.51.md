# CPA v8.0.51

2026-11-02（Asia/Shanghai）CPA 从官方 v8.0.47 更新至 v8.0.51。只切换官方 Linux amd64 含插件二进制，CPA 配置、认证文件、New API、CPAMP 和门户保持各自独立生命周期。

## 变更分析

v8.0.48–v8.0.51 的主要收益：

- 各提供商结构化用量，增加缓存 TTL、媒体及工具用量，保留旧 Token 与账号标识字段。
- Codex 没有续期凭据时不再自动反复刷新，保留禁用账号刷新退避及需要重新登录账号的隔离状态。
- 未完整结束的流不错误触发凭据冷却；修复插件同格式流式归一化/分帧。
- 修复 Responses 到 Chat 的 developer 角色、工具输出批次及模型切换上下文兼容。
- 扩充插件多 OAuth 入口和 locale 元数据，保持现有五个插件兼容。

按 Key 上游连接池与可见 Codex commentary 属于 opt-in 新能力；本次没有改写配置或开启新能力。结构化用量扩充不等于当前 CPAMP 页面已完整显示每个新字段，New API 售价也不会随 CPA 升级自动调整。
