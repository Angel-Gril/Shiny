# Shiny RU 的俄文协议正文

这两份 Markdown 用于 `https://ru.shinyapi.com`，由 RU New API 的既有法律文档功能展示：

| 文件 | RU 后台选项 | 公开页面 |
| --- | --- | --- |
| `user-agreement.md` | `legal.user_agreement` | `/user-agreement` |
| `privacy-policy.md` | `legal.privacy_policy` | `/privacy-policy` |

后台位置：RU 控制台“系统设置 → 站点设置 → 系统信息”中的用户协议和隐私政策。正文写入独立 `shiny_ru` 数据库，公开内容接口为 `/api/user-agreement` 和 `/api/privacy-policy`。通过 `/api/option/` 正常保存会同步运行配置，不需要重新构建或重启。填写后既有注册页会显示协议链接和勾选项；本次不增加服务端协议版本/接受时间记录。
