# Shiny RU 的俄文协议正文

这两份 Markdown 用于 `https://ru.shinyapi.com`，由 RU New API 的既有法律文档功能展示：

| 文件 | RU 后台选项 | 公开页面 |
| --- | --- | --- |
| `user-agreement.md` | `legal.user_agreement` | `/user-agreement` |
| `privacy-policy.md` | `legal.privacy_policy` | `/privacy-policy` |

后台位置：RU 控制台“系统设置 → 站点设置 → 系统信息”中的用户协议和隐私政策。正文写入独立 `shiny_ru` 数据库，公开内容接口为 `/api/user-agreement` 和 `/api/privacy-policy`。通过 `/api/option/` 正常保存会同步运行配置，不需要重新构建或重启。填写后既有注册页会显示协议链接和勾选项；本次不增加服务端协议版本/接受时间记录。

2026-11-27 版本基于当日实际部署核对：

- 品牌改为 Shiny RU，域名为 ru.shinyapi.com；运营主体和客服邮箱沿用主站已公布信息，不使用参考站 Rubilnik 的名称、域名或邮箱。
- RU 单独管理账户、Key、余额、订单和价格；同机使用独立数据库/账号，请求可通过主站渠道转发。俄语站点不代表俄罗斯本地数据存储。
- 当前 RU 新充值关闭，不宣称已开通 СБП、CryptoBot 或其他支付方式，也不承诺自动退款。真实支付、赠送、测试额度分别核查，不把总余额或兑换码名称直接当作可退现金。
- 删除参考稿未适用于本站的备用路线自动加价、封号余额全部不退及无条件固定退款时效；为计费错误、异议和强制性权利保留处理路径。
- 明确在主站路由上可能执行 SubQ 外部文本审核，不能宣称内容只交给生成模型、绝不保存或所有上游均为 ZDR。RU 自身模型审核关闭，主站使用 SubQ Shadow；不因本文更新改变开关。
- 说明必要 Cookie/本地偏好、可选保存功能、诊断内容、美国东部处理环境及加密 R2 备份。没有为尚未确认的各类留存时长编造统一删除日期。

发布时只更新 RU 这两项。主站法律正文、RU 付款/注册/邮件/安全设置、应用二进制和门户静态页面均不修改。发布验证包括公开 API 正文摘要、状态启用标志、桌面/手机渲染、注册页链接和勾选。后续若修改运营主体、支付、路由、审核服务或数据处理方式，应同步审阅正文；服务器数据库中的内容可以被管理员独立编辑，Git 版本不会自动覆盖。
